При пустом имени (или имени с пробелами, например `" "`) функция `subscribe` поднимет исключение `ValueError` с сообщением `"empty name"`.

**Подтверждение кодом:**

*   **Файл:** `demo/service.py`, **строка 4-5**:
    ```python
    if not name.strip():
        raise ValueError("empty name")
    ```
    Здесь проверяется, пустая ли строка после удаления пробелов. Если условие истинно, выполняется `raise`.

*   **Файл:** `demo/test_service.py`, **строка 18-20**:
    ```python
    def test_empty(self):
        with self.assertRaises(ValueError):
            subscribe(" ")
    ```
    В тесте явно проверяется, что вызов `subscribe(" ")` вызывает исключение типа `ValueError`.
