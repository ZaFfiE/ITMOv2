Вопрос: Как запустить тесты для проекта Notify Mini?

Ответ: Для запуска тестов выполните команду `make test` в директории проекта (см. файл `demo/Makefile`, строка 3). Это вызовет выполнение `python3 -m unittest -v`, используя стандартную библиотеку Python 3.10+ (см. файл `demo/README.md`, строка 5).
