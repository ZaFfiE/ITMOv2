# P1-02 — Результат запуска с Master Prompt v1

summary
- PR добавляет простой сервис обзора diff через LLM: метод `ReviewService.review` формирует prompt с полным diff и отправляет его в `llm.generate`, API `POST /api/reviews` проксирует поле `diff` из JSON и возвращает `{"comment": str}`.

risks
- file: app/review_service.py
  line: 20
  evidence: f"Review this pull request and find problems:\n{diff}" отправляет сырой diff во внешний LLM без маскировки
  risk: Нарушение SEC-1 — секреты/токены из diff не редактируются перед внешним вызовом.
- file: app/api.py
  line: 37
  evidence: return review_service.review(payload["diff"]) — вход без проверки размера
  risk: Нарушение API-1 — нет отклонения diff > 20 000 символов (ожидается 413).
- file: app/review_service.py
  line: 22
  evidence: return {"comment": answer}
  risk: Нарушение OUT-1 — ответ не содержит summary/risks/checks, только поле comment.

checks
- SEC-1: передать diff со строкой вида "token=abc123" и убедиться, что в prompt, уходящем в LLM, токен замаскирован ([REDACTED]) — ожидаемо сейчас провалится.
- API-1: отправить payload с diff длиной 20001 символ — ожидать HTTP 413; текущее поведение будет принимать запрос, что подтверждает риск.
- OUT-1: вызвать POST /api/reviews и проверить JSON-схему ответа — ожидать поля summary/risks/checks; текущее поведение возвращает только comment.
