## Context Pack для первого рабочего сценария

### Факты и правила

- SEC-1: секреты удаляются из diff перед внешним LLM.
- API-1: diff > 20 000 символов отклоняется (413).
- REL-1: timeout внешнего вызова 10с.
- OUT-1: ответ содержит summary, risks[≤3 с file,line,evidence,risk], checks.
- SCOPE-1: помощник не принимает решения и не меняет код.
- QA-1: риск включается только при подтверждении строкой diff или правилом.

### Формат входа и результата

- Вход: единственный diff TRAINING_PR.diff.
- Результат: структура summary/risks/checks (см. OUT-1).

### Ограничения и запрещённые действия

- Нельзя использовать внешние источники и домысливать факты вне diff/CASE/README.
- Нельзя выполнять действия в GitHub, approve/merge, писать код.

### Хороший пример

app/review_service.py:20 — diff отправляется во внешний LLM без маскировки, что нарушает SEC-1. Проверка: передать diff с «token=...», ожидать [REDACTED].
### Плохой пример

Код можно улучшить. Добавьте тесты.
### Что пока неизвестно

- Требования к аутентификации API; целевой язык ответа; политика логирования вне OBS-1.
